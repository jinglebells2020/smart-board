# Genesis: Smart Breadboard: tracks we are targeting (HackPrinceton F26)

## Main tracks
- Education (our required track): make learning more interactive,
  accessible, or personalized.
- Best Hardware Hack: creatively integrates hardware.
- Best Rookie Hack (only if eligible): first-time hackers.
- Best Overall (automatic). Track winners cannot also win it.

## Special tracks
- Amazon, Best Practical AI Innovation
  - Focus: agentic behavior, real-world impact, adaptive
    intelligence, user-friendly design, creative innovation.
  - Scoring: Creativity 25%, Usefulness 25%, Technical
    Implementation 25%, User Experience 25%.
  - Must include: working prototype, clear use case and target
    user, basic documentation, pitch.
- LangChain, Best use of deepagents: build a deepagent.
- Best Physical AI Hack: AI inside a physical hardware build.
- Peri, Forward Deployed Challenge
  - Solve a real problem for a real business or student
    organization consulted during the hackathon.
  - Must include: business name, name and role of person
    consulted, one piece of evidence (screenshot, photo, video,
    or quote).
  - Criteria: real-world need, usability, execution.

## What this means for the code
- Agent is built with deepagents and uses tools that act on the
  board. Not a chat wrapper.
- Agent adapts lessons to the logged mistake history.
- README states target user, setup steps, demo script.
- README has a "Consulted with" section for Peri evidence.
